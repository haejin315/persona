# 1 Pager · 답장 한 번의 원가와 매출: 어떤 모델을 써야 하는가

작성 2026-10-15 · 계산 스크립트 `scripts/unit-economics.ts` (`npm run econ`)

## 질문

AI 캐릭터 채팅에서 유저는 답장 한 번에 얼마를 내고, 우리는 그 답장을 만드는 데 얼마를 쓰는가.
그 차이가 모델 선택의 기준이다. "좋은 모델"이 아니라 "이 가격대에서 마진이 남는 가장 좋은 모델"을 골라야 한다.

## 유저가 내는 돈 (시장 데이터)

**위프(WHIF)는 크레딧 과금이다.** 메시지마다 선택한 모델 등급에 따라 위프가 차감된다.

| 모델 등급 | 위프/답장 | 원화 (1.19원/위프) | 수수료 15% 제외 순매출 |
|---|---:|---:|---:|
| 프리즘 | 24 | 28.6원 | 24.3원 |
| 아쿠아 | 54 | 64.3원 | 54.6원 |
| 아이리스/루비 | 64 | 76.2원 | 64.8원 |
| 이클립스/벨벳 | 80 | 95.2원 | 81.0원 |
| 시엘 | 120 | 142.8원 | 121.4원 |

- 위프 패키지는 1,900원/1,520위프(1.25원)부터 99,900원/91,908위프(1.09원)까지. 9,900원 팩(1.19원/위프)을 기준값으로 사용.
- 무료 유저는 출석으로 하루 200위프, 가입 시 1,000위프. 프리즘 기준 하루 약 8회 답장이 무료.
- 재생성(리롤)도 같은 위프가 차감된다. 즉 **재생성은 유저에게 비용이고, 재생성 횟수를 줄이는 것이 곧 유저 만족과 재구매에 직결된다.** "유저가 재생성 버튼을 덜 누르도록"이 매출 문장이기도 한 이유.

**비교군.** 제타(스캐터랩)는 기본 모델 무제한 무료(광고) + 제타패스 월 10,900원(웹)/14,900원(앱). Character.AI c.ai+ $9.99/월, Replika Pro $19.99/월. 글로벌 AI 컴패니언 앱 다운로드당 매출은 2025년 $1.18로 전년 $0.52의 두 배 이상. 제타 블로그는 일본 유저의 인당 매출과 사용 시간(하루 3시간 40분)이 한국을 능가한다고 밝힘.

## 우리가 쓰는 돈 (모델 원가)

답장 1회 토큰 프로파일은 이 저장소의 `v2-structured` 프롬프트에서 추정했다. **평가 파이프라인이 돌기 시작하면 API `usage` 실측값으로 교체한다.**

| 항목 | 추정 | 근거 |
|---|---:|---|
| 시스템 프롬프트 | 2,500 tok | 카드 ~3,100자 한국어 |
| 기억 블록 | 400 tok | 요약 + 사실 + 관계 |
| 최근 대화 창 | 4,000 tok | 20턴 × ~200 tok |
| 출력 | 350 tok | 한국어 답장 300~500자 |
| 캐시 적중률 | 85% | 접두부(시스템+기억+이전 턴)는 매 턴 동일 |
| 기억 정리 (5답장마다) | 800 / 120 tok per 답장 | 저가 모델로 처리 |

## 결론

1. **크레딧 과금은 모델 선택의 자유를 준다.** 위프의 최저 등급(24위프)에서도 gpt-5-mini급은 93% 마진이고, gpt-5나 Sonnet 5.5급도 아쿠아 이상 등급에서 80%를 넘긴다. 최상위 모델(Opus 5.5, gpt-5.5)은 시엘 등급(120위프) 이상에서만 성립한다. 위프의 등급 가격표는 실제로 이 원가 구조와 거의 정확히 맞물려 있다.
2. **구독 무제한은 자체 모델이나 nano/Haiku급을 강제한다.** 헤비 유저 1명이 gpt-5로 한 달에 25,000원을 태운다. 제타가 자체 모델(Spotwrite)을 만든 건 품질 선택이 아니라 생존 조건이다.
3. **원가의 지배 변수는 모델 단가가 아니라 컨텍스트 길이와 캐시 적중률이다.** 입력 6,900토큰 중 85%가 캐시에서 나온다는 가정이 깨지면(예: 매 턴 시스템 프롬프트가 바뀌는 설계) 원가는 3~5배로 뛴다. 프롬프트를 "고정 접두부 + 가변 꼬리"로 설계해야 하는 공학적 이유가 여기 있다.
4. **재생성은 원가이자 매출 누수다.** 크레딧 모델에서 리롤은 매출이지만, 리롤이 잦은 캐릭터는 유저가 떠난다. 평가 지표에 "재생성 유발 응답 비율"을 넣어야 한다.

## 이 저장소에 적용하는 결정

| 역할 | 모델 | 이유 |
|---|---|---|
| 기본 채팅 (무료/프리즘 등급 대응) | `gpt-5-mini` | 24위프에서 93% 마진. 품질 하한을 평가로 확인 |
| 저가 비교 축 (자체 모델 대응) | Ollama 로컬 7~8B, `gpt-5-nano` | 구독형이 강제하는 가격대. 캐릭터 일관성이 어디까지 버티는지 측정 |
| 프리미엄 비교 축 (시엘 등급 대응) | `gpt-5` (나중에 `claude-sonnet-5-5`) | 120위프 가격대에서 성립하는 상한 |
| 기억 정리 | `gpt-5-nano` | 답장당 원가에 0.05원 미만으로 묻힘 |
| 평가 채점 | `gpt-5` | 채점 대상보다 강한 모델. 호출 수가 적어 비용 무시 가능 |

**다음에 측정할 것.** 평가 러너에서 (a) 답장당 실제 입력/출력/캐시 토큰, (b) 모델별 재생성 유발률, (c) 턴 수에 따른 컨텍스트 증가 곡선을 수집해 이 문서의 추정치를 실측으로 바꾼다.
