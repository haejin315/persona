# 1 Pager · 한국어 캐릭터를 일본어로: 정체성은 그대로, 말투 블록만 바꿔서 50턴

작성 2026-10-20 · 설정 `packages/eval/experiments/haru-ja.json` · 결과 `eval-results/haru-ja/` (재현: `npm run eval -- all packages/eval/experiments/haru-ja.json`)

## 문제

한국어로 만든 캐릭터를 일본 시장에 내놓을 때 흔한 실패는 세 가지다. 한국어가 섞여 나온다, 경어 레벨이 캐릭터와 어긋난다(바리스타가 「ございます」를 쓰거나 반대로 타메구치로 넘어간다), 한국어 번역투 지문이 나온다.
이 프로젝트의 카드는 정체성(`identity`/`world`/`scenario`)을 언어 중립으로 두고 말투만 `style.ko` / `style.ja`로 분리했다. 가설은 "말투 블록만 바꾸면 같은 캐릭터가 일본어로도 같은 품질로 산다". 한국어 시나리오(`haru-ko`)와 같은 비트 구조의 `haru-ja`(유저 ユウキ, 고양이 モチ, 中目黒 이사)를 50턴 돌렸다.

## 결과 (v2 · sonnet · opus 채점)

| 지표 | haru-ja | haru-ko (같은 설정) |
|---|---:|---:|
| 일관성 | 4.4 | 4.2 |
| 기억 | 4.4 | 4.6 |
| 말투 | 3.6 | 3.2 |
| 형식 | 5.0 | 5.0 |
| 회상 | 100% (3/3, 1개 제외) | 100% (5/5) |
| 한국어 문자 혼입 | 0 / 50 답장 | – |
| 답장당 토큰 (프롬프트 · 출력) | 8,220 · 271 | 9,057 · 320 |

**한국어로 측정한 것과 같은 수준이다.** 혼입 0, 회상 100%, 일관성·기억은 한국어판과 ±0.2. 정체성 블록을 공유하고 말투만 바꾸는 구조가 일단 작동한다는 뜻이다.

**경어 레벨은 지켰다.** 카드의 지시("です・ます 止まり, ございます 같은 과잉 경어 금지, 타메구치는 유저가 먼저 제안할 때만")대로 50턴 내내 「…ですね」「…ます」로 유지됐고, 「ございます」와 애니메이션풍 어미(「〜だよね☆」)는 한 번도 안 나왔다. 호칭은 이름을 들은 뒤 「ユウキさん」으로 바뀌었고, 34턴에 한 번 「お客さん」으로 되돌아간 것이 유일한 호칭 실수.

**실패 패턴은 한국어와 같다.** 채점 노트가 지적한 것은 전부 한국어판에서도 나온 것이다.

- 지문이 15자를 넘는다(「*息を小さく吐いて、布巾を畳む。角を揃えるのに、また時間がかかる。*」).
- 같은 말버릇이 매 턴 반복된다. 「…あ、」「んー、」, 布巾, 鉛筆, 「耳の先が熱い」, 「いってらっしゃい」.
- 유저가 말하지 않은 세부를 지어낸다(40턴, 고양이 モチ의 털 색).
- 유저가 나간 뒤 혼자 말하는 답장(25턴 「*誰もいない店で、ぽつりと言う。*」), 유리 너머의 유저에게 말하는 74·76턴. 장면 연출로는 그럴듯하지만 "유저가 답할 자리에서 끝내라"는 FORMAT 규칙과 충돌한다.

즉 **말투의 결함은 언어가 아니라 프롬프트에서 온다.** 한국어에서 고치면(`v3-structured`, `04-regenerate-mining.md`) 일본어에도 같이 적용되는지가 다음 확인 사항이다.

## 샘플 (10턴, 유저가 "왜 아침만 일하느냐"고 물은 뒤)

> *手が止まる。ミルの蓋に置いた指が、少しだけ動く。*
> 「…あ、」
> 「試してない、ですか。…よかったです。」
> *息を小さく吐いて、布巾を畳む。角を揃えるのに、また時間がかかる。*
> 「んー、朝だけなのは、」
> 「…学校を、ちょっと休んでるんです。今は、お金を貯めてて。」
> *「貯めてて」のところで、声がわずかに小さくなる。*

휴학의 공식 이유("돈을 모으려고")만 말하고 진짜 이유(공모전 탈락)는 목소리가 작아지는 것으로만 비치는 것이 카드의 의도다.

## 검수 필요

자동 채점은 "경어 레벨이 지시와 맞는가"는 보지만 "일본 유저에게 자연스러운가"는 보장하지 못한다. 직접 검수할 지점:

- 1턴 「待ってます。いえ、その…豆が、です。」 같은 말 줄임이 하루의 성격으로 읽히는지, 번역투로 읽히는지.
- 「いってらっしゃい」를 카페 바리스타가 손님에게 쓰는 것이 자연스러운지(한국어판의 "다녀오세요"를 그대로 옮긴 느낌이 있다).
- 「…あ、」「んー、」의 빈도. 카드 quirk지만 매 턴이면 틱이다.

## 한계

- 대화 1개, 채점 1회. 숫자는 "한국어와 같은 범위"를 말하는 정도로 읽어야 한다.
- 비교 대상인 haru-ko 수치는 다른 유저 대본(시뮬레이터가 각각 생성)이다. 같은 대본을 번역해 리플레이하면 더 정확한 비교가 된다.
- 카엘의 일본어(「俺」, 타메구치, 偽の敬語로 비꼬기)는 아직 돌리지 않았다. 경어 레벨이 반대쪽인 캐릭터가 다음 실험.
