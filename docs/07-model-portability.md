# 1 Pager · 모델을 바꾸면 캐릭터 목소리가 유지되는가: sonnet vs haiku

작성 2026-10-20 · 설정 `packages/eval/experiments/model-r1.json` · 결과 `eval-results/model/` (재현: `npm run eval -- all packages/eval/experiments/model-r1.json`, 프롬프트 비교 실험 먼저)

## 문제

같은 캐릭터를 더 싼 모델(또는 자체 모델)로 서빙하려면 "어디가 얼마나 나빠지는지"를 알아야 한다. 이 실험은 같은 `v2-structured` 프롬프트, 같은 유저 턴(리플레이)으로 sonnet과 haiku를 비교한다. 정가 기준 haiku는 sonnet의 약 1/12 비용이다(`01-unit-economics.md`).

## 결과

| arm | 일관성 | 기억 | 말투 | 형식 | 회상 | 답장당 토큰 (프롬프트 · 캐시 · 출력) | 50턴 대화 정가 |
|---|---:|---:|---:|---:|---:|---|---:|
| v2 / sonnet | 4.60 | 4.60 | 3.60 | 4.94 | 83% | 11,131 · 4,129 · 434 | $1.12 / $1.82 |
| v2 / haiku | 3.70 | 3.70 | 3.50 | 5.00 | 83% | 10,352 · 4,077 · 542 | $0.06 / $0.09 |

**회상률은 같다.** 프로브로 되물은 사실은 haiku도 전부 맞혔다. 기억 블록이 사실을 명시적으로 들고 있으면 모델 크기와 무관하게 "나를 기억하네"는 성립한다. 프롬프트 설계가 모델 차이를 흡수하는 부분이다.

**일관성과 기억 점수는 0.9점 떨어진다.** 떨어지는 방식이 특징적이다. haiku는 사실을 잊지 않는데 **사실들 사이의 논리를 흐트러뜨린다**.

- 12턴에 "민수 씨"라고 불러 놓고 20턴에 "아니요, 아까 처음 들었잖아요"라고 말한다.
- 아침 7시 출근 전에 들르는 단골에게 32·40턴에 "집에 가서 자라"고 한다. 시간 설정은 프롬프트에 있지만 추론에서 빠진다.
- 74턴에 "이사 날짜 정해지면 말씀해 주세요"라고 하는데, 유저는 이미 "다다음 주 토요일"이라고 말했고 기억 블록에도 있다.
- 96·100턴에 하루가 문고리를 잡고 있는데 민수가 문을 잡고 있고 하루는 카운터에 있다. 공간이 꼬인다.
- 카엘은 38턴에 리아가 하지 않은 행동(과일을 굴렸다)을 한 것으로 말하고, 전투 장면에서 문장이 짧아져야 하는데 설명이 길어진다.

**말투 점수는 같다(3.5~3.6).** 둘 다 같은 이유로 깎였다. 지문이 길고, 같은 동작이 반복된다. 즉 말투의 결함은 모델이 아니라 프롬프트(few-shot 템플릿 복제)에서 온다. haiku는 거기에 "건조한 농담이 없다", "관찰보다 질문이 많다"가 더해졌다. 카드가 요구하는 유머와 관찰은 작은 모델이 가장 먼저 놓치는 부분이다.

**출력이 더 길다.** haiku는 답장당 542토큰으로 sonnet(434)보다 25% 길다. 싼 모델이 더 많이 쓴다.

**재생성 사유 분류(`04`의 분류기)로 보면 차이가 더 선명하다.** 100답장당 반복은 둘이 같다(71 vs 72, 프롬프트 탓). haiku에서만 올라가는 것은 유저 말 무시(0 → 10), 밋밋함(1 → 12), 캐릭터 이탈(8 → 19)이다. 유저가 물은 것에 답하지 않거나 무난한 말로 넘기는 답장이 haiku에서 네 답장 중 하나다.

## 해석

모델 교체 시 지표별로 다른 대응이 필요하다.

| 지표 | haiku에서 | 대응 |
|---|---|---|
| 사실 회상 | 유지 | 기억 블록 설계로 해결됨. 추가 작업 없음 |
| 논리 일관성(시간·공간·누가 무엇을 했나) | 하락 | 프롬프트로 일부 보강 가능(현재 시각·장소를 SCENE 블록에 명시), 나머지는 모델 한계 |
| 말투 반복·지문 길이 | 둘 다 나쁨 | 프롬프트 수정(`v3-structured`)이 두 모델에 같이 적용되는지 확인 |
| 유머·관찰 | haiku에서 소실 | 카드 example을 늘려도 될지, 상위 모델 전용 등급으로 둘지 선택 |

위프의 모델 등급제(24~120위프/답장)와 연결하면: 사실 기억은 하위 등급에서도 보장하고, 상위 등급의 차이는 "장면이 안 꼬인다"와 "농담이 산다"로 설명할 수 있다.

## 한계

- arm당 대화 2개. 일관성 0.9 차이는 채점기 노이즈(±0.4) 밖이지만, 말투 0.1 차이는 "같다"가 아니라 "구분 못 했다"로 읽어야 한다.
- 리플레이 비교라 유저가 haiku의 실수에 반응하지 않는다. 실제 대화에서는 "아까 말했는데요"가 들어오고 haiku가 그걸 어떻게 수습하는지가 추가 변수다.
- 비교 대상이 같은 벤더의 두 등급이다. 자체 모델/오픈소스(Ollama 어댑터)로 같은 실험을 돌리는 것이 다음 단계이고, 스펙 문자열(`ollama:qwen2.5:7b`)만 바꾸면 된다.
