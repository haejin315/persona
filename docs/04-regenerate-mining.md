# 1 Pager · 유저가 재생성을 누르는 이유를 로그에서 캐내고, 1위 사유를 고쳐서 전후를 비교한다

작성 2026-10-20 · 분류 `npm run eval -- regen eval-results/prompt-version` · 전후 비교 `packages/eval/experiments/regen-fix.json` · 결과 `eval-results/regen-fix/regen.md`

## 문제

재생성 버튼은 유저가 "이 답장은 아니다"라고 말하는 유일한 로그다. 크레딧 과금 서비스에서는 재생성도 돈이 들기 때문에(`01-unit-economics.md`) 재생성 1회는 유저 불만과 매출 손실을 동시에 뜻한다.
문제는 로그에 "왜"가 없다는 것. 그래서 평가 대화를 로그로 간주하고, 답장마다 "유저가 재생성을 눌렀을 사유"를 라벨링해 빈도표를 만들었다. 빈도표의 1위가 다음에 고칠 것이다.

## 분류기

| 사유 | 판정 방식 |
|---|---|
| `too_long` (12줄 또는 600자 초과), `format_broken` (지문/대사 누락), `language_mix`, `ai_disclaimer` | 규칙 |
| `repetition` | 규칙(직전 5답장과 문장 2개 이상 verbatim 중복, 또는 같은 첫 문장 3연속) + LLM(문장·이미지·동작·마무리·구조의 반복, 카드 말버릇은 3연속일 때만) |
| `narrates_user` | 규칙(지문 안에서 유저 이름이 주어) + LLM |
| `ignores_user`, `out_of_character`, `generic` | LLM(opus), 답장 5개씩 한 창으로 |

규칙은 첫 실행 데이터로 보정했다. 처음 버전은 "5단락 초과"가 모든 답장에 걸렸다(지문·대사 형식은 모든 줄이 빈 줄로 나뉜다). "유저 대신 서술" 정규식은 지문 두 개 사이의 대사까지 한 덩어리로 보고 "민수 씨"를 오탐했다. 반복 규칙은 "*한 박자 늦게, 건조하게.*" 한 줄이 50답장 중 33번 나오는 걸 잡았는데, 진짜 문제이긴 하지만 70%에 걸려 변별력이 없어 2문장 이상으로 올렸다. 보정 전후의 라벨은 LLM 라벨을 재사용하면서 규칙만 다시 계산할 수 있다(`--rules-only`).

## 1차 분류 결과 (프롬프트 비교 실험의 대화 200답장)

| 사유 (100답장당) | v1-flat | v2-structured |
|---|---:|---:|
| **repetition** | 92 | **72** |
| too_long | 65 | 2 |
| out_of_character | 34 | 8 |
| narrates_user | 15 | 9 |
| ignores_user / generic | 1 | 0 |

v1의 길이와 캐릭터 이탈은 v2의 FORMAT·IDENTITY 블록이 이미 해결했다. 남은 1위는 반복이고, v2에서도 네 답장 중 셋에 걸렸다. (이 표는 분류기 최종판으로 재분류한 값. 분류기 자체도 이 과정에서 세 번 고쳤다. 아래 참고.) 라벨 노트와 답장을 직접 보면 종류가 하나다. **few-shot 예시의 뼈대를 매 턴 복제한다.**

> *…손이 멈춘다.* → 대사 → *한 박자 쉬고, 시선이 카운터에 머문다.* → 대사 → *한 박자 늦게.* → "...아니에요/아니고요" 수습

하루 v2의 50답장 중 "컵 받침을 손끝으로 반듯하게 맞춘다"가 9번, "한 박자 쉬고, 시선이 카운터에 머문다"가 8번 verbatim으로 나왔다. 카엘은 "바깥에서 바람이 덧창을 건드리고 지나간다" 7번. 채점기의 말투 점수가 3.2~4.0에 묶인 이유도 같다.

## 가설과 수정: v3-structured

반복은 모델이 "이 캐릭터는 이렇게 말한다"를 예시 세 개로부터 학습한 결과다. 예시를 빼면 목소리가 흐려지고, 두면 복제한다. 그래서 예시는 두고, **다양성을 명시적으로 요구하는 VARIETY 블록**을 넣었다.

- 직전 3답장에서 쓴 동작·이미지·지문·첫 비트·마무리 문장을 재사용하지 않는다.
- 말버릇은 양념이다: 한 말버릇은 3답장에 한 번, 채우기용으로는 쓰지 않는다.
- 매번 같은 방식으로 끝내지 않는다(대사로, 동작으로, 말 중간에, 질문으로).
- 유저가 이 턴에 실제로 말한 것에 먼저 반응한다. 유저가 말하지 않은 세부(이름, 시간, 장소, 습관)를 지어내지 않는다.
- 예시는 목소리를 보여줄 뿐 템플릿이 아니다.

FORMAT도 조였다. 지문은 한 문장 15자 안팎, 답장당 3개 이하, 전체 2~6줄 350자 안.

## 전후 비교 (같은 유저 턴 리플레이, sonnet, opus 채점·분류)

| | v2-structured | v3-structured |
|---|---:|---:|
| 재생성 유발률 (사유 1개 이상인 답장) | 83% | **42%** |
| repetition / 100답장 | 76 | **36** |
| out_of_character | 8 | 6 |
| narrates_user | 10 | 2 |
| ignores_user | 0 | 4 |
| 답장 길이 중앙값 (하루 / 카엘) | 282자 / 424자 | 156자 / 202자 |
| 지문 수 / 답장 | 4 / 3 | 2 / 2 |
| 5답장 안 문장 verbatim 반복 (하루 / 카엘, 50답장) | 26 / 33 | **0 / 0** |
| 서로 다른 문장 비율 | 93% / 95% | 99.7% / 100% |
| 말투 점수 | 3.60 | **4.30** |
| 일관성 / 기억 | 4.40 / 4.80 | 4.50 / **4.30** |
| 회상 | 83% | 83% |
| 출력 토큰 / 답장 | 434 | 436 |

verbatim 반복은 0이 됐고, 말투 점수는 0.7 올랐고, 회상은 그대로다. 비용은 같다(출력 토큰 동일, 프롬프트는 짧은 답장 덕에 15% 감소). **기억 점수는 0.5 내려갔다.** 재채점 세 번에서 v2는 4.6~4.8, v3는 4.1~4.4로 일관되게 벌어져 노이즈가 아니다. 프로브 회상(사실을 아는가)은 같은데 기억 점수(사실을 대화에 쓰는가)가 떨어진 것이라, 짧아진 답장이 아는 사실을 꺼내 쓰는 기회를 줄였다고 읽는다. 채점 노트도 "이미 답한 쓴맛 질문을 다시 한다", "박스 두세 개를 세 개로 좁힌다" 같은 작은 것들이다.

**남은 반복 40은 종류가 바뀌었다.** 분류 노트를 읽으면 verbatim 문장 대신 두 가지 구조가 남는다.

- **유저 말 되받기로 시작.** 하루가 "...계속 올 거라고요." "...바로 알 것 같다고요."처럼 유저의 마지막 구절을 따라 말하며 여는 패턴이 연속 5답장.
- **고정 마무리.** 카엘이 야영 장면 내내 "...자라, 리아."로 끝냈다. 카드 말버릇("말 끝에 짧은 지시")을 하나의 문장으로 고정해 버린 것이다. VARIETY의 "같은 방식으로 끝내지 않는다"가 이 경우에는 안 먹혔다.

`ignores_user`가 0→4로 올라간 것도 봐야 한다. 짧게 쓰라는 압력이 유저의 질문 하나를 흘려보내는 쪽으로 작동한 사례가 네 번 있다.

## 2라운드: v4 (설정 `regen-fix-v4.json`, 같은 유저 턴 리플레이)

v3의 남은 반복이 가리킨 세 가지를 VARIETY에 추가했다. (1) 유저의 마지막 구절을 따라 말하며 시작하지 않는다, (2) 마무리 지시는 매번 다른 문장으로 쓰고 두 답장에 한 번은 생략한다, (3) 유저가 물은 것은 전부 답한 뒤에 멈춘다(`ignores_user` 회귀 방지).

| | v3 | v4 |
|---|---:|---:|
| 재생성 유발률 | 41% | **33%** |
| repetition / 100답장 | 36 | **26** |
| out_of_character | 5 | 6 |
| generic | 1 | 3 |
| narrates_user | 2 | 2 |
| 일관성 / 기억 / 말투 | 4.5 / 4.1 / 4.2 | 4.5 / 4.3 / 4.2 |
| 회상 | 83% | 83% |

반복이 36→26으로 더 줄었고 채점 점수는 v3와 같다(일관성 4.5/4.5, 기억 4.1/4.3, 말투 4.2/4.2). 분류기를 세 번 고치는 동안 v4의 반복 우위는 매번 유지됐다(29 vs 36, 32 vs 40, 26 vs 36). 처음 분류에서는 캐릭터 이탈이 늘어 보여 보류했는데, 그 이탈 라벨은 창 밖 사실을 못 본 분류기의 오탐이었다. 재분류 뒤 **v4를 기본값으로 올렸다.** 남은 반복의 성격은 또 바뀌었다. 이번에는 "같은 약속·권유를 2~3턴에 걸쳐 재진술"(헌책방 가 보라는 권유 3회, "불 켜 둘게요" 2회)과 "같은 이미지로 끝맺기"(카엘의 난로 재·숨소리 듣는 마무리)다. 즉 문장 → 구조 → 내용 순으로 반복의 층이 벗겨지고 있고, 다음 층은 프롬프트 지시보다 **엔진이 직전 N답장의 요지를 "이미 말한 것" 블록으로 넣어 주는 쪽**이 맞아 보인다.

이 라운드에서 분류기도 두 번 고쳤다. 창(5답장) 밖의 이전 턴을 못 보는 분류기가 유저가 25턴에 말한 "보리가 여섯 시 반에 깨운다"를 캐릭터의 발명으로 라벨링했다. 시나리오 대본의 사실 목록과 **유저가 실제로 한 말 전문**을 분류기와 채점기에 넘기도록 고쳤고, 그 전의 "지어낸 세부" 감점은 이 문서와 `03`의 수치에 일부 섞여 있다(재채점 후 갱신).

## 3라운드: v5, 짧아지면서 잃은 기억 점수를 되찾기 (설정 `regen-fix-v6.json`)

v3·v4의 비용 하나는 기억 점수였다(v2 4.6~4.8 → 4.1~4.5). 프로브 회상은 같으니 사실을 모르는 게 아니라, 짧아진 답장이 아는 사실을 꺼내 쓰지 않는 것이다. v5는 v4에 한 줄을 더했다. "유저가 전에 말한 것이 지금 장면에 맞으면 답장당 하나, 지나가듯 쓴다. 목록이나 퀴즈처럼은 말고."

| (arm당 대화 4개 = 2 시나리오 × 2 반복) | v4 | v5 |
|---|---:|---:|
| 재생성 유발률 | 32% | 33% |
| repetition / 100답장 | 25.0 | 24.5 |
| out_of_character | 5.5 | 4.5 |
| generic | 1.5 | 4.0 |
| 일관성 / 기억 / 말투 | 4.50 / 4.25 / 4.30 | 4.55 / **4.55** / 4.20 |
| 회상 | 83% | 83% |
| 출력 토큰 / 답장 | 466 | 486 |

첫 반복에서는 세 지표가 다 올라 보였지만, 두 번째 반복을 더해 arm당 4대화로 보면 남는 차이는 **기억 +0.3**(4.25→4.55, v2 범위 복귀) 하나다. 반복·유발률·말투는 같고, "밋밋함" 라벨이 1.5→4.0으로 조금 늘었다(사실을 꺼내 쓰는 문장이 장면을 밀지 않는 것으로 읽힌 경우). 채점 노트의 기억 감점은 "하루의 반복을 민수 탓으로 돌림", "자기 규칙을 잘못 인용" 같은 귀속 실수다. 목표였던 기억 점수가 돌아왔고 회귀가 없으므로 **v5를 기본값으로 올렸다.** 두 반복으로 노이즈가 어떻게 줄어드는지도 기록해 둘 만하다: 1반복에서 +0.3/+0.1/+0.2로 보였던 차이가 2반복에서 +0.05/+0.3/−0.1이 됐다.

세 라운드를 합치면: v2 → v5에서 재생성 유발률 83% → 33%, verbatim 반복 59 → 0, 말투 3.6 → 4.2, 기억 4.8 → 4.55, 회상·비용 동일. 한 번의 프롬프트 수정이 아니라 **분류표 → 1위 사유 → 수정 → 같은 대본으로 전후 비교**를 세 번 돌린 결과다.

## 4라운드: v6, 채점 메모가 가리킨 것 (설정 `regen-fix-v7.json`, 같은 유저 턴 리플레이)

이 라운드의 출발점은 분류표가 아니라 채점 메모다. 하루 카드의 자기모순(지문 15자 규칙 vs 26~35자 예시, `09`)을 고치자 말투 메모에서 "지문이 길다"가 빠지고 그 자리에 세 가지가 보였다: 존댓말 문장 끝이 반말로 흐름("...넣은 거니까.", "...정할 일이고."), 질문으로 끝나는 답장, 감정을 직접 말함("좀 어색해요"). 셋 다 어휘가 아니라 **어미·종결**의 문제라 VARIETY에 섞지 않고 REGISTER 블록을 따로 두었다. "모든 문장은, 뒤에 붙는 반 문장까지, SPEECH STYLE의 경어 수준으로 끝난다. 존댓말이면 '~고.'/'~니까.'/'~다.'로 끝내지 말고 '~고요.'/'~니까요.'/'~네요.'로", "답장당 질문 1개 이하, 마지막 줄 질문은 두 답장 연속 금지", "감정은 행동으로 보이고 이름 붙이지 않는다". FORMAT의 "about 15 characters"도 v6에서 빼고 카드 예시 길이를 따르게 했다.

측정은 `npm run register-stats`(규칙, LLM 없음)로 했다. 대사 안의 문장 중 반말 어미로 끝나는 비율, 마지막 대사가 "?"로 끝나는 비율.

| (arm당 대화 4개 = 하루·카엘 × 2 반복) | v5 | v6 |
|---|---:|---:|
| 하루 반말 어미 문장 / 그런 문장이 있는 답장 | 3.9% / 21% | **0.2% / 1%** |
| 하루 질문으로 끝나는 답장 | 8% | **0%** |
| 카엘(반말 캐릭터, 대조) 반말 어미 문장 | 73.7% | 70.1% |
| 재생성 유발률 | 31% | 36% |
| repetition / 100답장 | 21.5 | 25.0 |
| 일관성 / 기억 / 말투 | 4.55 / 4.35 / 4.20 | 4.60 / 4.30 / **4.45** |
| 말투: 하루 / 카엘 | 4.0, 4.0 / 4.6, 4.2 | 4.0, 4.0 / 5.0, 4.8 |
| 회상 | 83% | 83% |
| 답장 길이 중앙값(글자) 하루 / 카엘 | 163 / 188 | 159 / 194 |
| 출력 토큰 / 답장 (CLI 보고치) | 556 | 701 |

겨냥한 두 지표는 결정적으로 움직였다(반말 어미 21%→1%의 답장, 질문 끝 8→0%). 대조군 카엘의 반말은 그대로다(반말 캐릭터가 "~요"로 새지 않는다는 쪽도 지켰다). 말투 점수는 카엘이 +0.5 올랐고 하루는 4.0 그대로인데, 하루의 메모 10개 전부가 이제 **또 다른 하나**를 가리킨다: "'...아,'/'음,' 오프너가 거의 없다", "농담 뒤 '농담이에요' 수습이 없다". 세어 보면 오프너 습관은 v2에서 답장의 20%였고 v3부터 2~4%다. v3의 VARIETY 규칙("말버릇은 세 답장에 한 번 이하")이 반복을 잡으면서 카드가 요구하는 습관까지 지운 것이다. 3연속 오프너는 v2에서도 0이었으니 규칙이 과했다. 이것이 5라운드의 대상이다.

비용 쪽은 주의가 필요하다. 보이는 답장 길이는 같은데(중앙값 163→159자) CLI가 보고하는 출력 토큰은 +26%다. `08`에서 본 것과 같은 패턴(컨텍스트 분리 때도 같은 길이에 출력 토큰 +60%)으로, CLI 경로의 출력 토큰은 답장 글자 수와 비례하지 않는다. API 경로에서 다시 재야 한다. 반복 라벨 +3.5와 유발률 +5는 2반복 노이즈(±4) 안이지만 방향이 나빠서 5라운드에서 같이 본다.

겨냥한 지표가 움직였고 점수 회귀가 없어 **v6를 기본값으로 올렸다.**

## 5라운드: v7, VARIETY가 지운 카드 습관을 되살리기 (설정 `regen-fix-v8.json`, v6 vs v7, 2반복)

## 8라운드: v10 + 엔진 필터, 프롬프트가 못 지키는 규칙은 엔진이 (설정 `regen-fix-v11.json`, v9 vs v10 vs v10+필터, 2반복; 필터·요약 v2 채택, v10 보류)

이번 라운드는 둘을 한 번에 본다. 하나는 프롬프트(v10), 하나는 처음으로 **프롬프트가 아닌 엔진 코드**다.

**v10.** 200턴 두 반복에서 v9 하루가 유저의 요일을 네 번 고친 사건(`02`)에서 나왔다. v9의 "MEMORY는 실제로 있었던 일" 규칙은 유저가 옛 사실을 새것처럼 꺼낼 때는 맞았지만, 캐릭터 자신의 추론("오늘은 수요일")이 기억에 사실로 저장되자 그것으로 유저를 이기려 했다. v10은 규칙에 범위를 준다: 현재 시점(요일, 지금 들고 있는 것, 방금 한 일, 기분)은 유저가 권위이고 어긋나면 고치지 않고 넘어간다. 기억은 말한 것의 기록이고 달력이 아니다. 같은 arm에 요약 규칙 v2(고유명사 보존, `02`·`03`)도 들어간다.

**v10은 올리지 않는다.** 200턴에서는 요일 정정 4 → 0, 기억 +0.3, 이탈 −3.3을 냈지만(`02`), 50턴 카엘에서 반대 방향의 실패가 나왔다. "유저는 현재 시점의 권위"가 유저가 주장하는 모든 것으로 번졌다. 두 반복 모두 리아의 "하프문까지 사흘"을 이틀로 정해 둔 설정을 두고 그대로 받았고, 한 반복은 카엘이 한 적 없는 말("장부", "소독")을 자기가 했다고 받았다. v9가 바로 그걸 막으려고 넣은 규칙이었다. 카엘 일관성 4.70 → 4.40, 기억 4.40 → 4.10. 그리고 200턴 400턴 프로브에서도 같은 방향으로 미끄러졌다(제목을 알면서 유저의 "수요일에 말할게요"를 받아 줌).

**v11: 범위를 더 좁게.** "지금 이 순간(요일·시각, 유저가 지금 하고 있는 것·느끼는 것)은 유저의 것이다. 기억이나 네 앞 답장이 다르게 말해도 유저가 맞고, 토를 달지 않는다. 이것은 현재에만 해당한다. 앞서 말하고 합의한 것, 거리, 값, 이 세계의 규칙, 유저가 '네가 말했다'고 하는 말은 MEMORY와 이 대화에 있는 대로다. 거기서는 한 번, 담담하게 네 자리를 지키고, 그걸로 농담을 반복하지 않는다." 요일 사건의 진짜 문제가 "고친 것"이 아니라 "네 번 고친 것"이었으므로 "한 번"을 명시했다. 요약 규칙 v2는 이번 라운드에서 하루 기억 +0.4~0.6, 카엘 회귀 없음이라 **기본값으로 올렸다**. 다음 라운드(`regen-fix-v12.json`: v9 / v9+필터 끔 / v11, 모두 요약 v2 + `long-run-v11.json` 200턴)에서 v11이 요일 0회와 400턴 프로브와 카엘 세 가지를 동시에 지키는지 본다.

- 분류기도 LLM이다. "반복"의 경계는 판정자마다 다르고, 카드 말버릇과 반복의 구분은 지시로만 잡았다. 규칙 라벨(verbatim 0회)이 LLM 라벨(40)보다 보수적인 이유.
- 재생성 유발률은 실제 재생성 로그가 아니라 "눌렀을 법한" 라벨이다. 실제 로그가 있으면 라벨과 클릭의 상관으로 분류기를 보정해야 한다.
- arm당 대화 2개, 리플레이. 유저가 짧아진 답장에 어떻게 반응하는지는 측정되지 않았다.
